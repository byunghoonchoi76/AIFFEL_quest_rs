## 🔬 실험 2: Ablation Study — Deep Supervision 효과

### 실험 설계

| 모델 | 설명 | 에폭 | Learning Rate |

| 30 | 0.3478 | 0.3183 | 0.5731 |
| 40 | 0.3217 | 0.3117 | 0.5056 |

## 🔍 결과 분석

### 주요 발견

**1. B 모델(DS 없음)이 가장 높은 성능**
- B가 A(U-Net) 대비 +0.0443 향상
- U-Net++ 구조(nested dense skip connection) 자체의 효과 확인
- 이미지 2, 3번에서 U-Net을 명확히 초과

**2. C 모델(DS 있음)이 B보다 낮은 이유**
- Deep Supervision은 4개 Loss 동시 최적화 → 수렴에 더 많은 에폭 필요
- 200 에폭 학습에도 Loss 0.35 수준으로 미수렴
- 데이터 부족(170장)이 복잡한 모델 학습에 불리하게 작용

**3. 이미지 1번에서만 DS 효과 확인**
- 이미지 1: DS 효과 +0.0066 ✅
- 이미지 2, 3: DS 효과 음수 ❌
- 데이터셋 특성에 따라 DS 효과가 다르게 나타남 (논문과 동일한 경향)

### Loss 수렴 비교

```
A (U-Net)   Epoch 100 Loss: 0.2696  → 수렴 ✅
B (DS 없음) Epoch 100 Loss: 0.2529  → 수렴 ✅
C (DS 있음) Epoch 200 Loss: 0.35~   → 미수렴 ⚠️
```

## 📌 최종 결론

| 항목 | 결과 |
|------|------|
| U-Net vs U-Net++ | 소규모 데이터(170장)에서 U-Net이 더 안정적 |
| Skip Connection 개선 효과 | B 모델이 A 대비 +0.0443 → **구조 개선 유효** ✅ |
| Deep Supervision 효과 | 현재 실험에선 부정적 → 추가 학습 필요 ⚠️ |
| C 모델 미수렴 원인 | 에폭 부족 + 데이터 부족 |
