## 주요 발견 사항

### 정량 지표 요약

| 지표 | 값 | 의미 |
|---|---|---|
| 프롬프트 A-B 코사인 유사도 | 0.6580 | 두 개념이 의미적으로 다름 |
| SSIM 최저 구간 | step 2→3 | 이 구간에서 개념 전환 발생 |
| 사진 보간 코사인 유사도 | 0.9772 | 두 사람 사진 프롬프트는 유사 |
| LoRA 파일 크기 | 151.1 MB | Checkpoint(~4GB) 대비 경량 |
| DreamBooth 학습 시간 | 10.4분 (강아지) / 12.0분 (사람) | T4 GPU 기준 |

### 핵심 관찰

1. **Latent Space 연속성**: alpha 값이 증가할수록 이미지가 점진적으로 변화하며, SSIM 최저 구간이 개념 전환 지점과 일치
2. **CFG Scale 영향**: CFG가 높을수록 프롬프트 반영도 상승, 다양성 감소 trade-off 확인
3. **DreamBooth 효과**: 5장의 Instance 이미지만으로 특정 대상(sks dog) 정체성 학습 가능
4. **LoRA 경량성**: 151MB 파일로 전체 스타일 변환 가능 (Checkpoint 대비 약 1/30 크기)
5. **Negative Prompt**: 전체 적용 시 가장 안정적, 해부학 관련 제거 시 신체 비율 이상 발생
